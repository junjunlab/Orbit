# Orbit 1.0.2

Orbit 1.0.2 is about alignments and about what you can read off a gene model.
BAM/SAM files now arrive as three labelled tracks that behave like IGV's, every
read in the window is kept, and right-clicking a gene model tells you exactly
which exon, CDS/UTR fragment or intron is under the pointer — including the
coordinates and length of every intron in the transcript.

Downloads: `Orbit-1.0.2-Windows-x64-Setup.exe`, `Orbit-1.0.2-macOS-arm64.dmg`,
`Orbit-1.0.2-macOS-x86_64.dmg`.

## Alignments

**Three tracks per file.** One BAM or SAM now produces `Coverage`, `Junctions`
and `Alignments`, drawn next to each other and each labelled with the file name,
so several imported BAMs stay distinguishable. Junctions are arcs coloured by
strand; the arc height follows the number of supporting reads.

**No sampling, no cap.** The old 6,000,000-read import limit and the display
sampling are gone. Every read that passes the flag filters and overlaps the
window is returned, and the track label reports the count. Wide windows on deep
libraries take longer because they ask for more data, not because anything is
being thinned out.

**Indexes.** A neighbouring `sample.bam.bai` is used as-is. When it is missing,
unreadable or inconsistent with the BAM, Orbit builds its own index once, caches
it next to the imported copy, and reuses it afterwards. Only BAI is supported;
CSI indexes are not read.

**Visibility window by experiment type.** Coverage, junctions and alignments
share IGV's rule: 30 kb for a standard library, 300 kb for RNA-seq, 1000 kb for
third-generation reads. Orbit estimates the type from the first reads it sees
(read length, spliced-read fraction, CIGAR complexity); the result is shown in
the track settings and can be overridden, along with an explicit maximum window.

**Four display modes.** Right-click the Alignments track for `Collapsed`,
`Expanded`, `Squished` (the new default) and `Full`. No mode drops reads — they
change how many rows fit on screen.

**Scroll through every row.** Put the pointer inside the Alignments track and use
the wheel. The label reports the visible range (`Rows 16–39 / 157 · scroll
up/down to browse`) and a thin bar on the right edge shows the position. Only the
visible rows are painted, so tens of thousands of reads scroll without another
request. Ctrl + wheel still zooms.

**Independent rows.** Each of the three tracks has its own sidebar checkbox;
hiding Junctions or Alignments leaves coverage alone, and "Remove current track"
hides the row without deleting the BAM.

## Gene structure details

Right-click a gene model in RefSeq or in an imported GTF/GFF3 track. The popover
reports the gene name, gene ID when the annotation stores one, transcript ID,
strand, and what is under the pointer: which exon of how many, which CDS or
5′/3′ UTR fragment, or which intron — each with its 1-based inclusive interval
and length. Numbering follows the transcript, so on a minus-strand gene the
leftmost exon is the last one.

The full intron list is one click away: all of them in transcript order with
coordinates and lengths, the current one in bold. Hovering an intron shows the
same information in a tooltip without opening anything.

The popover can be dragged by its title bar, stays inside the window, and scrolls
when the intron list is long.

## Export

SVG and PDF export failed outright on any view containing splice junctions
(`ctx.bezierCurveTo is not a function`); the vector recorder now handles cubic
and quadratic curves. PNG, SVG and PDF were then checked against the window:
the PNG matches the view pixel for pixel, the SVG carries the same 218 paths and
27 text labels, and the PDF is a single page with an embedded CJK font, a
ToUnicode map and no raster images.

## Startup and interface

- A launch no longer reopens anything. Imported copies stay under `data/loaded`
  and the registration list is kept, but nothing is parsed, indexed or drawn
  until you import the file again in that session, so a 900 MB BAM can no longer
  hold up the window. Importing the same file again replaces its stored copy in
  place instead of adding a `_2` duplicate. Set `IGV_RESTORE_LOADED=1` if you
  prefer the old "reopen everything" behaviour.
- English interface: remaining Chinese strings are gone, including the track
  group label and panel counts. A regression test now walks every translatable
  string and fails on any Chinese left in English mode.
- The sidebar track list grows with the window instead of stopping at 176 px, and
  long file names wrap so `chr1` / `chr2` remain readable.
- Track and gene popovers are clamped to the window and re-clamped when their
  content grows.

## Installer rebuild (2026-10-31)

The installers attached to this tag were rebuilt after the first upload: the
original build predated a fix for the ruler drawing with the wrong canvas width,
which collapsed every tick label into the left ~60 px on custom assemblies and in
some split-view states. Source changes since then are limited to `src/web/app.js`
(`paneWidth` / `refreshPaneW`). If you downloaded a package before this note
appeared, download it again.

## Known limitations

- BAI only; CSI indexes are not read.
- The self-built index has been validated against an independent sequential scan
  of the same BAM, but not formally against samtools/HTSJDK output.
- Index building reports no progress and cannot be cancelled.
- The bundled RefSeq index stores gene names but not gene IDs, so that field
  reads "not provided" there.
- CDS/UTR fragment numbers are derived from the exon list and the transcript's
  CDS bounds, not from the original annotation's feature numbering.
- CNV summary values were not re-derived from the IGV source in this release.
